# Mostrar información de excel a tabla

A partir de los datos del reporte de báscula, aplicar todas las funciones de filtrado propias para mostrar una tabla con todos los datos de filtrado.

## ¿Qué hace?

Se debe iniciar filtrando el reporte por la columna Placa Vehiculo: Utilizando la función esPlacaNuestra, descartamos los registros que inicialmente no son de valor, sin embargo, NUNCA se eliminan, sino que se guardan en una tabla de revisión manual a la que se puede acceder y posterior a ello añadir registros de nuestras placas a la tabla principal de visualización.
